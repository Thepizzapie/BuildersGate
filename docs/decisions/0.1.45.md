# [0.1.45] - 2026-09-06

Moved verbatim from `CHANGELOG.md`; links inside are as written there, relative to the repository root.

### Added
- **The modelling kit builds the smooth shape FIRST: hull, skin, blob, tube,
  round, rock.** Measured on Meridian's coupe: repairing a box-built car
  (fuse, bevel, bake) made a lump with disc wheels. The blocky look is decided
  by the vocabulary of the first script, so the kit gains the ways a modeller
  starts a form that was never blocky, each a one-call `.glb` tool as well:
  `bg_hull`/`blender_hull` (a body from its side x top silhouettes, one
  rounded shell - a coupe from two polygons in 2 s), `bg_skin`/`blender_skin`
  (a body from a stick figure of joints with radii), `bg_blob`/`blender_blob`
  (metaballs that merge by construction), `bg_sweep`/`blender_tube` (a
  tapering tube along a path), `bg_round` (subdivision that keeps creased
  edges), `bg_rock`/`blender_rock` (a seeded boulder that sits on the ground)
  and `bg_form_help` with the worked coupe, quadruped and rock. The art
  brief's form bullet leads with these; `bg_fuse` is the repair for shells
  you already have.
- **Surface tools: fuse, shade, lathe, loft, eleven material presets, bake,
  decals.** Measured on Meridian (2026-09-05): a tree of octagonal prisms
  shoved through one another, a 116k-triangle car with eleven flat colours
  and zero textures, headlights floating in front of the fender. Not a
  modelling-skill problem: the kit was `bg_box`, `bg_cyl` and join, so that
  is what got built. The kit gains `bg_fuse`, `bg_shade`, `bg_lathe`,
  `bg_loft`, `bg_material` and `bg_surface_help`, and seven tools run the
  same source on a file: `blender_fuse` (join, voxel remesh union, smooth,
  decimate, materials carried from the nearest original face),
  `blender_shade` (weld, bevel by angle, smooth by angle, weighted normals),
  `blender_lathe`, `blender_loft`, `blender_material` (presets; a `.blend`
  sidecar keeps the node graph a glTF cannot), `blender_bake` (Cycles
  albedo/roughness/normal/AO to PNG, rewired so the glTF ships real textures)
  and `blender_decal` (shrink-wrapped, alpha-clipped sheets). What the coupe
  and pine then taught: fuse coarsens its remesh toward the target and
  decimates in passes; shade skips a bevel that would grow the mesh past
  1.5x; image-less Principled inputs export their flat colour instead of
  white; a bake keeps transmissive and emissive constants instead of turning
  glass black.
- **`blender_tree`, `blender_scatter` and `blender_look_audit`.** A tree as
  ONE swept, tapered, voxel-fused surface plus one mesh of alpha-clipped leaf
  cards, bark preset applied, deterministic per seed (Sapling is an extension
  in 4.2+, not bundled, so a headless machine cannot rely on it).
  `blender_scatter` lays area-weighted copies of one mesh over another's
  faces as one mesh. `blender_look_audit` measures what makes a model read as
  shapes tacked together - disconnected shells inside one object, hard
  unbevelled edges, split vertices from a glb round trip, materials with no
  image map, no UVs, parts touching nothing, objects over budget - on a
  WELDED copy, and each finding names the tool that fixes it. The art brief's
  step 7 is "blender_look_audit, THEN blender_turnaround".
- **Live Blender: the kit inside a Blender that stays open.** `blender.run_script`
  launches a fresh headless Blender per call; nothing survives between calls
  and nobody sees the viewport. Blender Lab's MCP extension (5.1+) opens a
  socket into a running Blender, and this adapter speaks it: the kit is
  installed once as a module (`bgate_kit`) and every call is
  `from bgate_kit import *` plus the script under a temp_override of the
  first 3D view. Tools: `blender_live_status`, `blender_live_run`,
  `blender_live_view` (the human's viewport through the OpenGL render),
  `blender_live_export`, `blender_live_reset`.
- **`mesh_faceting`: the gap between the silhouette and the triangle count.**
  Reads a `.glb` without spawning Blender and reports dent, stale, sliver and
  inverted fractions against thresholds; classified in the 3D craft beside
  `skin_dominance`.
- **`blockout_generate`: a measured 3D graybox from a spec or a level_plan.**
  Rooms and corridors in metres, doors cut through ONE shared wall with a
  lintel, box props resting on their floor by construction, spawn, goal
  volumes for `traversal_prove`, a baked NavigationRegion3D, preview camera,
  sun and environment - every piece a named node. Then it measures walkable
  floor per room, door and corridor widths against the agent, heights against
  the player, and a real NavigationServer path from the spawn to every room.
  `from_plan` converts a BSP `level_plan`. Engine facts it carries: build in
  `_process` not `_init`, wait for the map's first sync, 0.1 m nav cells
  because 0.25 bakes a 1.6 m corridor to nothing.
- **`godot_scene_audit` and `godot_export_verify`: the 3D gates every game
  hand-wrote and none shipped.** Static: boot scene set and not the scaffold
  demo, a sub_resource shared by several nodes and assigned into by a script,
  an instanced scene resizing its own embedded sub_resources without
  `resource_local_to_scene`, a concave shape under a moving body. In-engine,
  world space, after two physics steps: every visible mesh has a matching
  collider, every body above the floor rests on something, every landing
  surface has headroom. `godot_export_verify` fingerprints one scene from the
  project and from the pck and diffs - the Corniche liveries would have been
  one row.
- **The 3D scaffold is third-person, with a prop kit and an arcade vehicle
  demo.** Camera-relative controller, orbit/follow/fixed rig on a SpringArm,
  platform/ramp/crate/pickup/trigger props, and the vehicle model that felt
  right on Corniche, distilled into `vehicle_demo.tscn`. Same telemetry
  contract; imports, runs and audits clean.
- **Chaos dispatch mode: every run in its own worktree, integration bounded.**
  Completed branches are prepared and handed to the Director for
  `worktree_merge`. A branch that conflicts or is handed over without landing
  `MAX_INTEGRATION_ATTEMPTS` times fails the item instead of prompting the
  Director every five minutes for the life of the server; a dirty working
  branch holds integration with one floor refusal. Switching mode no longer
  force-enables autopilot. New projects get a standalone git repository.
- **Codex seats: forwarded MCP identity, isolated config, bounded
  auto-approval.** Dispatch env var names reach the seat's MCP server through
  `mcp_servers.<name>.env_vars`; `codex exec` runs with
  `--ignore-user-config` and `--approve-for-me`; a Codex prompt ending is not
  completion. The director console runs Codex as an app-server over stdio
  with approvals surfaced in the chat; auto-approval, when the human switched
  it on, covers Builders Gate MCP calls and commands inside the project,
  never permission prompts or another directory. Schema 0046 adds
  `integrating` to `work_item.status`.

### Changed
- **A dispatched agent carries the tools it was measured using, not 203.**
  `--allowedTools` is a permission list, not a restriction; availability is
  `--tools`, which the runner never passed, so a dispatch naming six tools was
  handed 203-229 - Task and Workflow among them, so every seated agent could
  spawn subagents. The list is now what 76 runs actually used: the six, plus
  `ToolSearch` and `PowerShell`. `--strict-mcp-config` is passed, reversing a
  documented decision on measurement: zero calls to any non-bgate MCP server
  across those runs, ~110 tools' schemas re-read on every turn regardless.
- **Autodeploy refuses to spawn an item whose brief names a leased file.**
  The PreToolUse hook refuses the write, but by then the agent is spawned and
  has read half the repo; one file blocked six items and one of them burned
  two rounds discovering a collision the board already knew. The dispatcher
  reads the live path leases first and cools the item for 90 s. It fails OPEN
  on an unreadable lease store, and an item never blocks on its own lease.
- **The tool schema bills the contract, not the essay.** 256 tools carried
  378,589 characters of docstring - ~105,000 tokens in every agent's context
  on every turn. The wire description is now the first paragraph plus a
  pointer to the source; the full note stays where a person can read it.
  `blender_run`'s first paragraph names the four help functions and the three
  base bodies so the kit stays discoverable from the schema.
- **In a 3D project the cast is GENERATED; every visible mesh routes to
  art.** Hot Cargo 2026-09-04: the director wrote "no imported meshes" into
  the bible on its own and a full run shipped 21 box scenes and zero
  generated models with Krea keyed the whole time. The director mission says
  the cast comes from the keyed 3D provider, primitives are the graybox
  stage, and a constraint forbidding generated meshes needs `ask_human`
  first. Art's lanes reach `game/scenes/{props,characters,vehicles,kit}/**`;
  tech keeps the collider, layers and wiring under the mesh.
- **The Builders Gate checkout itself is refused as a project root** at
  adopt, scaffold, store init and the dashboard form. A game had been
  scaffolded into this tree and the tree adopted.
- **The test suite lost 144 prose-pinning tests and can no longer launch
  real agents.** 144 tests whose every assertion was a sentence fragment `in`
  a brief pinned wording, not behaviour; the dispatch prompt's byte-for-byte
  oracle is replaced by the contracts it carries. Two autouse guards stub the
  autodeploy pump's thread and resolve `find_claude`/`find_codex` to None -
  three real agents with `--max-turns 200` had been found running against
  pytest temp games after a run.

### Fixed
- **`blender_animate` runs on Blender 5.x.** Slotted actions moved the curves
  into layers -> strips -> channelbags and 5.x dropped the `Action.fcurves`
  shim; the LINEAR pass died before any clip exported. The helper reads
  whichever the running build has.
- **The director console died at spawn on Windows with a >8 KB system
  prompt.** It rode on argv through the npm `.cmd` shim past cmd.exe's
  8,191-char limit; it is written to `.bgate/console/director-system.md` and
  passed with `--append-system-prompt-file`.
- **Playtest told every adopted project it had no game.** The native-build
  check looked for `game/project.godot` only; it checks both layouts and
  names both paths when it finds neither.
- **Dashboard and MCP project creation re-root the seat lanes to the
  scaffold's layout.** `bgate init` and `adopt` already did; `project_create`
  and `project_init` did not, so every seat's writes were out of lane.
- **SessionStart read the raw autopilot doc; project_create left the active
  pointer behind.** The hook now asks `settings.get`; creating a project from
  the dashboard registers and activates it.
- **Audio Lab: mp3 probing, an edited mp3 saves as a sibling ogg,
  `encode_ogg` no longer raises.** `probe()` asks the ffprobe beside the
  resolved ffmpeg; an mp3 save target becomes `<stem>.ogg` beside the
  untouched take; `proc.run` no longer defaults stdin to DEVNULL when the
  caller passes `input=`.
- **The rig anatomy verdict fails a trunk it could not measure.** `fit_trunk`
  records where the height-only template had each trunk bone and how far the
  measured fit moved it; `ok` false with "TRUNK ASSUMED" while `rigged` stays
  honest.
- **Agent commits and chaos merges carry a fallback author when the repo has
  none.** Linux CI runs with no git identity; a command-local identity now
  precedes commit and merge when none is configured.
- **Two tools were registered as `blender_sweep`; the tube is
  `blender_tube`.** The layer-file cleanup and the form kit's swept tube
  shared a name and the later one silently won.
- **`bgate_track_gen.gd` preloaded a path that only exists after
  `track_generate`,** so every scaffolded project failed Godot import; the
  preload is relative now.

### Security
- **Audio Lab paths are contained in the shape CodeQL recognises; `project_create`
  keeps exception text out of the reply.** `relative_to` already refused
  escapes but the analyser does not model it; the same check is made as
  `normpath` + prefix on the base, the mp3-to-ogg redirect target passes the
  same gate, and the lanes fallback logs its exception instead of returning
  it.
