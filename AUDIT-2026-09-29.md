concern — an ignore rule believed to be working is exactly how a key reaches a
public repo.

### Gaps

1. **Pillow deprecation is a scheduled runtime break.** The *only* deprecation
   warning the entire suite emits: `Image.Image.getdata is deprecated and will be
   removed in Pillow 14 (2027-10-15)` — 40 occurrences from **31 call sites across
   11 modules** (`art/vfx.py`, `art/chroma.py`, `art/tilemask.py`,
   `art/framegate.py`, `art/spritekit.py`, `art/artdirection.py`,
   `level/roomqa.py`, `cine/cinecut.py`, `adapters/blender.py`,
   `adapters/sprites.py`, `bgate_mcp/server.py`). `Pillow>=12.3.0` carries **no
   upper cap**, so the day Pillow 14 releases, `pip install builders-gate` resolves
   to it and the art pipeline raises `AttributeError` at runtime. The project caps
   `ruff<0.13` and `demucs<5` for considerably smaller reasons.

2. **The JS half of the repo sits outside every dependency gate.**
   `dependabot.yml` declares `pip` and `github-actions` only — no `npm` entry for
   `/frontend`, despite a committed `package-lock.json` (React 19, Vite 6,
   Mantine 9) whose build output ships inside the wheel. `security.yml` has no
   `npm audit` step either. Clean today; nothing keeps it that way, and it is the
   one ecosystem with no weekly watch.

3. **CodeQL analyses Python only.** `languages: python`, while `frontend/src` is
   ~37k lines of TS/React that renders agent output and chat content. The
   narrowing rationale written into that file is about *rule suites*
   (`security-and-quality` opening 277 alerts), not about excluding a language.

4. **`npm run typecheck` exists but CI never runs it.** No `tsc` step in `ci.yml`,
   so a type error can land and surface only indirectly via `frontend-drift`.
   Passes today.

5. **Coverage holes are narrow but specific.** `routes/window.py` 0/5 — the
   desktop-shell control surface (`/api/window/close|drag|maximize|minimize|state`);
   `routes/tiers.py` 0/1; `queue_ops.py` 6/14; `refs.py` 9/16; `brainstorm.py`
   15/26; `storyboard.py` 37/50.

6. **`src/bgate_mcp/server.py` is 10,717 lines** — largest module by ~4,000 lines,
   and the `tools_*.py` siblings show the splitting pattern already exists.

## Suggested Enhancements

### 1. Cap Pillow, then migrate off `getdata` — maintainability, highest value

`Pillow>=12.3.0,<14` in `pyproject.toml` today: one line, buys time, matches the
existing `ruff<0.13` precedent. Then sweep the 31 call sites to
`get_flattened_data`. Then add a Pillow-scoped `-W error::DeprecationWarning` to
`[tool.pytest.ini_options]` so the next one fails loudly instead of accumulating
40 warnings nobody reads.

### 2. Put `/frontend` under the same watch as Python — security

```yaml
  - package-ecosystem: "npm"
    directory: "/frontend"
    schedule:
      interval: "weekly"
    open-pull-requests-limit: 5
    labels: ["dependencies"]
```

plus an `npm audit --audit-level=high` step in `security.yml`'s weekly job. Goes
green immediately.

### 3. Close the PII leak at its source — security

`git config --global user.email Thepizzapie@users.noreply.github.com` on the
authoring machine; enable *Block command line pushes that expose my email*; confirm secret
scanning + push protection is on under Settings → Code security — the item
`security.yml` itself flags as outstanding. Fix the backslash `.gitignore` pattern
to `.github/instructions/codacy.instructions.md` in the same pass.

### 4. Audit the extras' floors too — security

`dep_floors.py` documents skipping `stt`/`voice`/`stems`/`desktop`/`build` because
they "pull heavy native trees that do not resolve on a plain runner". That is true
for *installing* — I reproduced the failure (`av` needs `libavformat` via
pkg-config, and plain `--no-deps` still runs a pip dry-run, so it fails too). But
`pip-audit --no-deps --disable-pip -r` skips resolution entirely. Verified
end-to-end here: `demucs==4.1`, `faster-whisper==1.0`, `playwright==1.47`,
`pyinstaller==6.14`, `pywebview==5.0`, `sounddevice==0.4`, `websockets==13`,
`comtypes==1.2` audit in seconds with no toolchain, and currently report no
advisories. The documented blocker does not apply to that invocation, so ~10 lines
of YAML closes the last unaudited floors.

### 5. Add the two cheap CI gates — maintainability

`npm run typecheck` as a step in `ci.yml`, and `javascript-typescript` added to
CodeQL's `languages`. Both pass now, so both land green and only ever fire on a
regression.
