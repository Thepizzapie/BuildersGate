# builders-gate-floor-assets

The dashboard's studio floor: the cast sprites and room paintings under
`img/`, and the lounge radio's soundtrack under `audio/`. About 30MB, all of
it decoration, so it is a separate package rather than 30MB in every
`builders-gate` install.

```bash
pip install "builders-gate[floor]"          # from an index
pip install -e packaging/floor-assets       # from this checkout
python packaging/build_floor_assets.py      # a wheel, in dist/
```

The dashboard (`bgate_ui.app`) resolves the floor's assets in this order:
this package if it imports, then `src/bgate_ui/static/{img,audio}/floor` if a
local tree has them, else the floor draws its procedural fallback and the
radio reports "floor assets not installed".

The version tracks the main package's `pyproject.toml`; bump both together.

## audio/

Generated by `scripts/gen_floor_music.py` and listed in `audio/manifest.json`.
The floor reads the manifest; no manifest means no soundtrack. To drop a track,
delete the mp3 and run the generator with `--manifest-only`, which rebuilds the
manifest from what is on disk.

These are harness UI audio, not game assets, which is why they do not go
through `music_generate` -> `music_keep` -> `music_install` (that path installs
into the engine project's music library).
